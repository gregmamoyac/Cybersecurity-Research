# Cybersecurity Research and Applied Security Projects

This repository contains a collection of cybersecurity research papers, technical presentations, machine learning security projects, and security-focused data analysis completed through graduate studies, independent research, and applied cybersecurity coursework.

The projects explore emerging cyber threats, adversarial machine learning, authentication security, vulnerability analysis, and cybersecurity policy challenges.

## Repository Contents

### Adversarial Machine Learning and AI Security

#### AI-Cybersecurity_FGSM Attack

**Files:**

* `AI-Cybersecurity_FGSM attack.ipynb`
* `AI-Cybersecurity_FGSM attack.pptx`

Research and implementation of the Fast Gradient Sign Method (FGSM), an adversarial machine learning attack used to evaluate the robustness of artificial intelligence and deep learning models.

Topics Covered:

* Adversarial AI
* Machine Learning Security
* Model Evasion Techniques

* Defensive AI Strategies
